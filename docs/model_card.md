# Model card — SwasthTwin 2-hour hyperglycemia risk model

> Research prototype trained and evaluated **only on synthetic data**. Not a medical device.
> All numbers below come from `reports/metrics.json` (generated by `make evaluate`).

## Intended use

* **Task:** estimate P(`hyperglycemia_event_within_120m`) = probability that any CGM reading in the next
  120 minutes is ≥ 180 mg/dL, for one adult with type 2 diabetes or prediabetes, every 30 minutes.
* **Intended user:** a clinician or researcher reviewing a patient, as one input among many.
* **Out of scope:** diagnosis; treatment, insulin or medication decisions; autonomous alerts; children;
  type 1 diabetes; pregnancy; hospital in-patients; hypoglycemia prediction; any real-patient use without
  validation and regulatory review.

## Model

* scikit-learn `Pipeline`: median imputation with missing-value indicators + standard scaling for numeric
  inputs; most-frequent imputation + one-hot encoding for categorical inputs; then the classifier.
* Candidates: logistic regression, random forest, histogram gradient boosting, plus a non-ML rule baseline.
* **Selected:** histogram gradient boosting (highest validation PR-AUC: 0.977 vs 0.973 random forest,
  0.943 logistic regression).
* **Alert threshold:** 0.858 — the highest threshold reaching ≥ 80 % sensitivity on validation patients.
* Artifact: `artifacts/model_pipeline.joblib`; metadata (features, threshold, version, reference row):
  `artifacts/model_metadata.json`.

## Inputs (42 features)

| Stream | Features |
|---|---|
| EHR (historical) | age, sex, BMI, diabetes status, years since diagnosis, HbA1c, fasting glucose, eGFR, LDL, triglycerides, systolic BP, hypertension, medication class |
| Sensor (dynamic) | latest CGM, minutes since last CGM, 15-min rate of change, 30-min trend, 60/120-min mean, 60-min SD, 120-min min/max, time in 70–180, CGM coverage; HR 30/120 min; HRV 60 min and vs own 24 h; steps 30/120 min; active minutes; wearable coverage; last night's sleep duration and quality; hours since waking; logged carbs (120 min); minutes since last logged meal |
| Context | time of day (sin/cos), weekend |
| Fusion | latest CGM − EHR fasting glucose; HbA1c × logged carbs |

All features use only data with timestamp ≤ prediction time (verified by `tests/test_features_leakage.py`).

## Evaluation (synthetic held-out test patients)

Split by patient: 48 train / 16 validation / 16 test patients; 10,275 test forecasts; prevalence 47.6 %.

| Model | ROC-AUC | PR-AUC [95 % CI] | Brier | Sensitivity | Specificity |
|---|---:|---:|---:|---:|---:|
| Rule baseline | 0.886 | 0.880 [0.750–0.940] | 0.147 | 0.709 | 0.897 |
| Logistic regression | 0.941 | 0.943 [0.872–0.972] | 0.096 | 0.808 | 0.908 |
| Random forest | 0.969 | 0.970 [0.928–0.986] | 0.073 | 0.825 | 0.963 |
| **Gradient boosting (selected)** | **0.975** | **0.975 [0.939–0.988]** | **0.063** | **0.772** | **0.984** |

* Harder subset (latest CGM < 180 mg/dL, prevalence 26 %): PR-AUC 0.867 (selected) vs 0.472 (rule) vs 0.701 (logistic).
* Temporal hold-out (train days 0–9, test patients days 10+): PR-AUC 0.976.
* Test sensitivity (0.772) is **below** the 0.80 validation target: thresholds did not transfer exactly.
* CIs: patient-level cluster bootstrap, 300 resamples, percentile method.

## Explanations

* Global: permutation importance on test patients (top: latest CGM, time of day, HbA1c, hours since waking).
* Local (dashboard): replace one input — or a whole stream — with the median/mode of training patients and
  re-score; the change in probability is shown. Not additive, reference-dependent, **associations not causes**.

## Limitations and risks

* Synthetic, hand-tuned data; performance is agreement with the simulator, not clinical accuracy.
* Time-of-day shortcut learned from regular synthetic meal times.
* Prototype target and risk bands are not clinically validated; probabilities are not calibrated for clinical use.
* Small cohort (16 test patients) → wide confidence intervals.
* Sensor-gap subset is small (366 test rows); its numbers are indicative only.
* Fairness across sex, age or medication groups was not evaluated; the synthetic data cannot support it meaningfully.
